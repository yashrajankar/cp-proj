Import Instructions

  1. Download the appropriate template for the data you want to import
  2. Fill in your data following the column structure shown above
  3. Save the file as a CSV or Excel format
  4. Go to the corresponding section in the admin panel
  5. Click the "Import Data" button and select your file
  6. Review the import results and address any errors if necessary
Important: Make sure to follow the exact column structure. Any deviation may cause import failures. Both CSV and Excel formats are supported for all imports.
